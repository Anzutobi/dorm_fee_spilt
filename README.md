# 宿舍水电费分摊计算器

这是一个使用 Python Tkinter 编写的宿舍水电费分摊工具。程序会根据每个人在对应计费周期内的住宿天数，分别计算水费和电费，再相加得到每个人应缴的总金额。

## 运行环境

- Windows
- Python 3
- Tkinter（大多数 Windows Python 安装已自带）

## 启动程序

1. 安装 Python 3，并确认命令行可以使用 `python` 命令。
2. 打开 PowerShell 或命令提示符。
3. 运行程序：

   ```powershell
   python dorm_fee_split.py
   ```

也可以直接双击 `dorm_fee_split.py` 启动；如果双击后窗口一闪而过，建议使用命令行启动，以便查看错误提示。

## 使用步骤

### 1. 填写费用和计费周期

在“费用与计费周期”区域分别填写：

- **水费金额**：本次水费总金额，单位为元。
- **电费金额**：本次电费总金额，单位为元。
- **水费开始日期、结束日期**
- **电费开始日期、结束日期**

日期必须使用 `YYYY-MM-DD` 格式，例如：

```text
2026-10-01
```

水费和电费可以使用不同的计费周期，程序会分别计算。

### 2. 填写每个人的住宿日期

每行填写一个人的姓名和在宿舍的日期范围。

单个连续日期范围：

```text
2026-10-01~2026-10-15
```

多个不连续日期范围用逗号分隔：

```text
2026-10-01~2026-10-15, 2026-10-20~2026-10-31
```

也支持使用以下分隔符：

- `~`
- `～`
- `至`
- 逗号、中文逗号、顿号或空格，用于分隔多个日期段

日期范围包含开始日期和结束日期。例如 `2026-10-01~2026-10-01` 会计算为 1 天。

如果姓名留空，程序会自动使用“室友1”“室友2”等名称。

### 3. 点击“计算分摊”

程序会显示：

- 水费和电费各自的计费周期
- 每个人在水费周期和电费周期内的住宿天数
- 每个人应分摊的水费
- 每个人应分摊的电费
- 每个人应缴的总金额
- 所有人合计应缴金额

## 计算方式

水费和电费分别计算，不会混用计费周期。

某人的水费计算方式：

```text
个人水费 = 水费总额 × 个人在水费周期内的住宿天数 ÷ 所有人住宿天数总和
```

某人的电费计算方式：

```text
个人电费 = 电费总额 × 个人在电费周期内的住宿天数 ÷ 所有人住宿天数总和
```

最后：

```text
个人应缴总额 = 个人水费 + 个人电费
```

## 示例

假设：

- 水费：100 元，周期为 `2026-10-01~2026-10-31`
- 电费：200 元，周期为 `2026-10-01~2026-10-31`
- A 在宿舍：`2026-10-01~2026-10-31`
- B 在宿舍：`2026-10-01~2026-10-15`

程序会分别按水费周期和电费周期统计 A、B 的住宿天数，再按住宿天数比例分配对应费用。

## 输入错误提示

- 费用不能填写负数。
- 日期必须是有效的 `YYYY-MM-DD` 日期。
- 结束日期不能早于开始日期。
- 日期范围必须写成“开始日期~结束日期”。
- 如果所有人在某项费用周期内的住宿天数都是 0，该项费用无法分摊。

## 重置

点击“重置”会清空费用，并恢复默认日期、姓名和住宿日期。

注意：重置按钮中的默认姓名为“室友A”“室友B”“室友C”“室友D”。
